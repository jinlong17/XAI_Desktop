# plugin-widgets API

Public exports:
- `WidgetHost`
- `WidgetFrame`
- `useWidgetStore`
- `createWidgetRegistry`
- `builtInWidgetManifest`
- `TimeProgressWidget`
- `CountdownWidget`
- `HabitStreakChart`
- `HabitWeeklySummary`
- `HabitCalendarHeatmap`
- `WallpaperAwareContrast`

External plugins should expose a `WidgetManifestRegistration` from their public surface.
