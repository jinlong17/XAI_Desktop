## 0. 2026-06-04 configurable meditation upgrade

This update supersedes the original v1 "visual-only" meditation contract where
the two differ.

- Persistence is `schemaVersion: 3`; `validatePrefs` migrates older v1/v2/unknown
  blobs by filling the new fields.
- Ambient sound is functional through Web Audio synthesis. No external audio
  files are bundled; this avoids missing-resource and license drift. The six
  non-silent presets are water, rain, waves, thunder, forest, and white noise.
- Clock style now includes 12 variants, size (`compact / normal / large /
  larger`) and five color slots (`digits / hands / ring / background /
  highlight`).
- Duration supports fixed presets, user-added fixed durations, custom minutes,
  and infinite mode.
- Users can save, select, edit, and delete custom scenes. A custom scene stores
  name, background color, gradient colors, animation, ambient sound, clock
  style, clock colors, and default duration.

## 1. Frozen assumptions (17)

   `@repo/plugin-web-meditation`. Mirrors matrix / habits Q1 resolution.

   `src/internal/`.

    `packages/plugin-web-storage/src/internal/registry.ts` near line 92.
    Append `xai_meditation_prefs` entry to `PREF_REGISTRY` (end-of-block,

    `meditationSlotRegistration` imported from `@repo/plugin-web-meditation`.

    stored in `customFixedDurations`; custom and infinite modes are stored
    separately.

## 2. Decision headline

Selected **Option C — package at `packages/xai-web-meditation/` named
`@repo/plugin-web-meditation`**, with:

- **Single-blob persistence** in `xai_meditation_prefs` (new
  `WebPrefRegistry` entry, JSON codec, schemaVersion 1, owner
  `xai-web-meditation`, `proposed: false`).
- **CSS-only fullscreen overlay** (`position: fixed; inset: 0; z-index:
  100`) — no shell coordination, no new event channels.
- **Inline 7 SVG icons** in `internal/icons.tsx` (`close / sound /
  soundOff / rain / timer / play / dots`) — paths copied byte-for-byte from
  `web design/icons.jsx` where they exist; for `close` use the standard
  `M18 6 6 18M6 6l12 12` path.
- **5 scene gradients** copied verbatim into `internal/scenes.ts` from the
  prototype's `MOCK.meditationScenes` (already in `oklch()`).
- **Live ClockDisplay component** — pure renderer with
  `setInterval(setNow, 1000)` ticker (skipped when `static`). 12 variants
  across digital, split, analog, minimal, and breath-ring styles.
- **Module slot registration** via `WebModuleSlotRegistration` from
  `@repo/xai-web-shell` — swapped into `shellRegistrations.tsx:59`
  (`moduleId: "meditation"`, `icon: "leaf"`, `railOrder: 9`).
- **`prefers-reduced-motion`** honored: particles hidden, breathing ring
  static at `scale(0.8)`.
- **Web Audio ambient engine** — actual audio is generated procedurally, so
  missing file assets do not break playback.

### 5.2 Hydration (`internal/useMeditationPrefs.ts`)

```ts
import { usePref } from "@repo/plugin-web-storage";
import { validatePrefs } from "./validate.js";
import type { MeditationPrefs } from "../types.js";
import { DEFAULT_PREFS } from "../constants.js";

export function useMeditationPrefs():
  [MeditationPrefs, (next: MeditationPrefs) => void] {
  const [raw, setRaw] = usePref("xai_meditation_prefs", DEFAULT_PREFS);
  const safe = validatePrefs(raw);            // clamps unknown ids
  return [safe, setRaw];
}
```

### 5.3 Validation (`internal/validate.ts`)

```ts
const SCENE_IDS: SceneId[]            = ["forest","ocean","night","rain","void"];
const CLOCK_VARIANTS: ClockVariant[]  = ["digital","split","analog","minimal"];
const SOUND_IDS: AmbientSoundId[]     = ["none","water","rain","waves","forest"];
const DURATIONS: Duration[]           = [5, 10, 15, 25, 45];

export function validatePrefs(raw: unknown): MeditationPrefs {
  if (!raw || typeof raw !== "object") return { ...DEFAULT_PREFS };
  const r = raw as Partial<MeditationPrefs>;
  return {
    schemaVersion: 1,
    scene: SCENE_IDS.includes(r.scene as SceneId) ? r.scene as SceneId : DEFAULT_PREFS.scene,
    clock: CLOCK_VARIANTS.includes(r.clock as ClockVariant) ? r.clock as ClockVariant : DEFAULT_PREFS.clock,
    sound: SOUND_IDS.includes(r.sound as AmbientSoundId) ? r.sound as AmbientSoundId : DEFAULT_PREFS.sound,
    duration: DURATIONS.includes(r.duration as Duration) ? r.duration as Duration : DEFAULT_PREFS.duration,
  };
}
```

## 6. Pure helpers (`internal/`)

### 6.1 `getScene(id: SceneId): Scene`

```ts
import { SCENES } from "./scenes.js";

export function getScene(id: SceneId): Scene {
  // SCENE_IDS literal-union ensures id is always one of the 5; the find is
  // a safety net for runtime divergence (e.g. mid-flight schema drift).
  return SCENES.find(s => s.id === id) ?? SCENES[1]; // fallback = ocean
}
```

### 6.2 `formatRemaining(remainingSec: number): { mm: string; ss: string }`

```ts
export function formatRemaining(remainingSec: number): { mm: string; ss: string } {
  const safe = Math.max(0, Math.floor(remainingSec));
  return {
    mm: String(Math.floor(safe / 60)).padStart(2, "0"),
    ss: String(safe % 60).padStart(2, "0"),
  };
}
```

### 6.3 `computeAnalogAngles(now: Date): { h: number; m: number; s: number }`

```ts
export function computeAnalogAngles(now: Date): { h: number; m: number; s: number } {
  return {
    h: ((now.getHours() % 12) + now.getMinutes() / 60) * 30,
    m: (now.getMinutes() + now.getSeconds() / 60) * 6,
    s: now.getSeconds() * 6,
  };
}
```

## 12. Out of scope (explicit)

- **Audio playback** — `<audio>` element is not instantiated. Per
  DESIGN.md §13 + seed brief, actual ambient sound is a future row.
- **Resume after reload** — `active` + `elapsed` are not persisted.
- **Custom durations / scenes** — locked to the 5 + 5 + 4 + 5 enumerated
  values. Custom-duration input is a future row.
- **Session history** — not recorded. Statistics row #20 sees no event
  from meditation. (Future: `web:meditation:session-completed` channel
  can be added in a follow-up row when statistics needs it.)
- **Stats integration** — out of scope for #16. Statistics row #20 will
  add the event-bus consumer once meditation declares an emit; not now.
- **Reduced-data mode** — not implemented (orthogonal to motion).

## 2026-09-09 failed-save recovery

A visible alert offers Retry save, Export draft and Discard change. The custom-scene editor stays editable after a failed save; starting a different scene or an unrelated mutation is blocked until the proposal is resolved. New scene ids are only installed into editor state after persistence succeeds, preventing the previous failed-new→empty-map retry bug. Failed deletion retains both stored scene and editor draft. Recovery controls have 44px minimum height and remain above the player if a volume save fails. Downloads explicitly disclose settings/custom scenes/unsaved edits and manual recovery only.
