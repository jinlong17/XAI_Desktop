# x25519-device-keypair — Test Strategy

## Acceptance Criteria

| Criterion | Verification |
|---|---|
| Device keychain key is account/device scoped | `cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml --features crypto crypto::device_key::tests` |
| Device private key is generated by CSPRNG path and stored through Keychain abstraction | Same target, `generates_device_key_with_csprng_and_stores_private_in_keychain_and_vault`. |
| Device private key is resident in KeyVault as `DevicePrivate` | Same target. |
| Keychain-loaded device private key can be rehydrated into KeyVault and public key recomputed | Same target, `import_device_private_recomputes_public_and_keeps_handle_resident`. |
| All-zero and low-order public keys are rejected | Same target, `rejects_all_zero_and_low_order_public_keys`. |
| Default and crypto builds compile locked | `cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml --locked`; `cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml --features crypto --locked`. |
| Exact crypto pins remain enforced | `bash scripts/ci/check-exact-pins.sh`. |

## Deferred

- Real macOS Keychain ACL / signed-build verification.
- `device_pub` upload to Supabase `sync_devices.device_pub`.
- Independent cross-vendor crypto/security review.
