## Decisions

| Decision | Selected | Rationale |
|---|---|---|
| Encoding scope | Fixed integer-key maps for blob, wrap, and recovery-message schemas | Avoids generic CBOR ambiguity and preserves PRD §7.1.2 ordering. |
| Writer | Custom deterministic writer for uint/bstr/text/map length | Guarantees shortest definite-length encodings, no tags, no indefinite lengths. |
| `ciborium` usage | Exact-pinned optional `ciborium = 0.2.2`; tests parse generated bytes with `ciborium` | Satisfies Rust CBOR dependency while keeping canonical ordering under local control. |
| Fixtures | `apps/desktop/src-tauri/tests/fixtures/cbor_aad_vectors.json` | Stable admission-gate artifact for future JS/Python/Rust cross-implementation checks. |

## Security Notes

- The writer only exposes schema-specific functions; callers cannot construct arbitrary maps with unsorted keys.
- AAD bytes are not stored in envelopes. Downstream encrypt/decrypt paths must recompute them from entity/wrap/recovery context.
- Blob-swap integration tests are deferred until envelope and sync-engine rows exist.

## Deferred

- JS `cbor-x` and Python `cbor2` cross-implementation verification were not run in this local autorun.
- Blob-swap integration test is deferred until `cipher-envelope-codec` / sync-engine rows.
