# superpowers

**Purpose.** Adopt the upstream "Superpowers" plan-first / subagent-driven discipline before touching code: decompose the task into reviewable sub-tasks, surface assumptions, and only then execute. The shim is description-triggered: agents load it when the conversation matches one of the trigger phrases below.

## Triggers

- "plan first"
- "design before code"
- "subagent-driven"
- "decompose this task"
- "multi-step planning"

## How to deepen

The full SKILL.md, reference assets, and examples live upstream at
<https://github.com/obra/superpowers>. Pull the upstream `SKILL.md` (and any
referenced playbooks) on demand when a task needs the deeper material — this
shim deliberately keeps the in-tree footprint small (no vendored upstream
content). See the vendor card for license, sync owner, and the recorded
upstream commit pin.
