## 故障排除

### 问题 A: Box 仍然遮挡其他应用

**可能原因**: 窗口层级设置不正确

**诊断步骤**:
1. 检查 `src-tauri/src/lib.rs` 中的 `setLevel_` 值
2. 当前应该是 `setLevel_(-1)`

**解决方案**:
- 尝试调整为 `setLevel_(0)` 或 `setLevel_(-2)`
- 重新编译: `pnpm tauri clean && pnpm tauri dev`

---

### 问题 B: 无法点击穿透到桌面

**可能原因**: CSS pointer-events 未生效

**诊断步骤**:
1. 打开浏览器开发工具（如果可用）
2. 在控制台运行:
   ```javascript
   console.log(getComputedStyle(document.body).pointerEvents); 
   // 应该输出 "none"
   ```

**解决方案**:
1. 检查 `src/index.css` 是否有 `pointer-events: none !important`
2. 检查是否有其他样式覆盖
3. 确保 `!important` 标记存在

---

### 问题 C: Box 和 AI Cube 也无法点击

**可能原因**: pointer-events: auto 未正确应用到交互元素

**诊断步骤**:
1. 检查 `.smart-container` 是否有 `pointer-events: auto`
2. 检查 `.ai-cube` 是否有 `pointer-events: auto`

**解决方案**:
- 确保 `App.css` 中有明确的 `pointer-events: auto !important`
- 增加 CSS 优先级或添加 `z-index`

---

### 问题 D: 在某些区域穿透，某些区域不穿透

**可能原因**: 元素层叠或 CSS 选择器冲突

**诊断步骤**:
1. 使用开发工具检查问题区域的元素
2. 查看 computed styles 的 `pointer-events` 值

**解决方案**:
- 确保所有容器层（app-shell, interactive-layer）都有 `pointer-events: none`
- 只有具体的交互组件应该是 `auto`
