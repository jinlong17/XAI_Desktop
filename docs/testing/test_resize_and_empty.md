## 故障排除

### 问题 A: Box 仍然有 Mock 数据

**可能原因**: `createGrid` 仍在调用 `generateMockItems`

**诊断步骤**:
1. 检查 `packages/plugin-organizer/src/useGridSystem.tsx`
2. 找到 `createGrid` 函数
3. 确认 `itemIds: []` 是空数组

**解决方案**:
```typescript
const createGrid = useCallback((x: number, y: number) => {
  const id = toId();
  const base = defaultGrid(id, x, y);
  // 应该是空数组，不调用 generateMockItems
  const nextGrid: GridBox = { ...base, itemIds: [] };
  setGrids((prev) => [...prev, nextGrid]);
}, []);
```

---

### 问题 B: Resize 句柄不可见

**可能原因**: react-resizable 的 CSS 未导入

**诊断步骤**:
1. 检查 `SmartContainer.tsx` 是否导入了:
   ```typescript
   import "react-resizable/css/styles.css";
   ```

**解决方案**:
- 添加上述导入语句到 SmartContainer.tsx 顶部

---

### 问题 C: Resize 时 Box 移动

**可能原因**: Resize 句柄与 Draggable 冲突

**诊断步骤**:
1. 检查 Resize 句柄的 `pointer-events`
2. 确认句柄的 `z-index` 足够高

**解决方案**:
```css
.react-resizable-handle {
  pointer-events: auto !important;
  z-index: 100;
}
```

---

### 问题 D: 无法 Resize 到小尺寸

**可能原因**: `minConstraints` 设置过大

**诊断步骤**:
1. 检查 `<Resizable>` 的 `minConstraints` 属性
2. 当前应该是 `[150, 150]`

**解决方案**:
- 调整 `MIN_SIZE` 常量到合适的值（如 100）
