Branch 为什么不等于产品线

对一个人、两台电脑并行开发来说，branch 先服务“稳定性和集成节奏”。产品线是地图，branch 是交通规则。

管理原则
两台电脑的默认分工：

这台电脑可以继续作为 `web` 主线和系统治理线；另一台电脑作为 `dev` / Desktop RC 线。Web 改动先进入 D3 gate，再决定是记录、合入 `desktop-next`，还是派发桌面补丁。

这样分的好处：

不会因为“有 6 个产品线”就制造 6 条长期分支。长期 branch 只保留给会影响集成、发布、冻结的阶段。
