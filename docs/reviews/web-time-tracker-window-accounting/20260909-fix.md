## Delivered behavior

- `internal/time.ts`: `entriesInWindow` / `entriesOnDay` create read-only report views with WeakMap window/source metadata. Views retain the original id and original segments; JSON serialization remains identical to the source (tested). `sourceEntry` returns the exact original object. Metadata never goes to storage. Nested views intersect, never widen. `accountingSegments` clips each pause segment separately to `[from,min(to,now))`; full raw entry duration also excludes future ends.
- `entryDayTotals` uses local civil midnight boundaries. `entryHourTotals` partitions elapsed time at epoch-minute boundaries before folding into local wall hours, preserving repeated/skipped DST hour totals and sub-minute remainder. Day counts and hourly counts use unique source entries instead of segment counts.
- Main selected day/today/week, category/subcategory goals and detail, trend, every Insights fixed/range aggregation and widget snapshot share these primitives. No first-start/day attribution or whole-segment/hour loop remains in the module. Fixed 7/30-day and 105-day charts retain their explicit fixed range; custom time-status countdown/month/year progress retain their separate calendar semantics.
- All Insights report filters (week/month/year/custom/all) use positive window contribution and cap now. Active lifecycle cards continue to show whole current task elapsed time. Recent sessions intentionally show complete actual sessions, excluding wholly future records. A crossing record can appear on each intersecting day but has one stable id.
- The main record row shows selected-day contribution; its tooltip separately gives complete-record duration. Its editor receives the source object and raw times. Delete-range receives original ids and explicitly warns that complete crossing records, including time outside the selected range, are deleted. No derived segment is persisted.
- CSV keeps existing columns and appends source id, effective ISO range, IANA timezone, original ISO source start/end and exact contribution milliseconds. Duration minutes no longer rounds each entry; formatted duration remains display text. Range-summary longest value is labelled “Longest contribution in range”.
- Existing REL03 hooks had 9 missing stable scope dependencies and a test unused import: included those dependencies/removal to restore owner lint without weakening rules.
