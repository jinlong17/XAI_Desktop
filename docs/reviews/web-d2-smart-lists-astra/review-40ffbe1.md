## Source review

The product changes only the pane, its narrow helper, labels/styles, and focused tests. `isSmartListsMap` requires a non-null non-array map of string own entries, restricting the twelve known modes while preserving unknown string extensions. `smartListVisibilityFor` uses `Object.hasOwn`; proposal construction copies own entries into a null-prototype map, preventing a `__proto__` assignment from changing object inheritance. Registry codec/default/ownership and migration validation remain unchanged.

The pane uses the registered `usePrefAutosaveAsync` binding with that stable validator. Its latest-map ref updates immediately for each local row intent, adopts idle/saved snapshots, and is reinitialized for owner epoch changes. Invalid/unavailable sources disable edits. The current hook value drives rendered selects and its actual status drives pending/saved/recovery feedback. Retry delegates to the accepted hook's captured operation/token; explicit conflict/source Reload delegates to its read-only session reset. There is no unprotected direct writer in this pane. The independent scenarios above exercise the important ref/Promise/session interactions rather than accepting the source shape alone.

Existing SL1–SL6 tests were not modified by the product commit; four author recovery cases and their local native-signature lock helper are additions. No business assertion was deleted to obtain the full package PASS. Shared hook/engine behavior is reused; this review does not reopen the accepted foundation or claim the remaining global reset writer is coordinated.
