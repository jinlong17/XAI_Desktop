## Short Description

Organize files, tasks, projects, and account-safe sync controls from a native macOS desktop surface.

## Long Description

XAI Desktop brings local-first organization to the macOS desktop. Smart containers keep files and workflows visible, while the console brings tasks, projects, devices, and encrypted export controls into one release-ready surface. Optional sync is designed around encrypted records and per-device controls.
