# Release Site Archive (Reference Only)

This package is an archive-only reference snapshot of the former Next.js web shell.

- Status: archive-only, reference-only.
- `/console` content here is a historical static mock, not product truth.
- Canonical browser product host: `@repo/web` in `apps/web`.

Do not use this package as a primary app target.

- No standard `dev` / `build` / `start` scripts are exposed.
- Optional manual archive inspection commands are available as `archive:dev` and `archive:build`.
